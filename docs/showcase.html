在自己的机器上保留一轮记录

uv run python examples/offline_demo.py
# 已完成环境安装后，可禁止下载：
uv run --offline python examples/offline_demo.py

从仓库根目录运行。需要 Python 3.11+ 与 uv；首次环境安装可能下载构建依赖。默认写入 studies/demo，已有目录会拒绝覆盖。再次运行请指定新的 --output 路径。
