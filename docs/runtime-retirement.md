# Runtime history

The Node/Pi runtime, its Cactus remote adapter and persistent-coding spike have been retired from the current source tree. Their code and historical documentation are available in Git at revision `2089620`. The historical reports include `docs/durable-research-evidence.md`, `docs/autodl-cactus-evidence.md`, `docs/verification.md`, `docs/verification-v2.md`, and `docs/meta-loop-verification.md` at that revision. Those reports describe the conditions and limitations of the earlier implementation; they do not validate the current Python/Codex runtime.

Existing runs and remote jobs are not migrated or stopped by retiring source code. Inspect and reconcile their original records and job identities separately. The [public release history boundary](public-release.md) remains in effect.
